## 🚀 How to Use This System

### For Immediate Use

**Step 1: Understand Subagent Coverage**
- Open: `AGENTS.md` → Section: "Quick Subagent Reference"
- Review table of 15 subagents with their memory file paths
- Takes: 2 minutes

**Step 2: Choose Right Subagent**
- Open: `AGENTS.md` → Section: "Decision Tree"
- Follow flowchart to identify correct subagent
- Takes: 1 minute

**Step 3: Invoke with Memory File**
- Copy code example from "How to Use Subagents" section
- Provide specific task description
- Include memory file path
- Takes: 2 minutes

**Step 4: Validate Output**
- Review generated code
- Test in development environment
- Deploy when verified
- Takes: 5-15 minutes depending on task

### For Common Scenarios

**"I need to create a new DocType"**
→ See: `AGENTS.md` → Example Workflows → Scenario 1, Step 1

**"I need to create API endpoints"**
→ See: `AGENTS.md` → Example Workflows → Scenario 1, Step 2

**"I need to optimize database performance"**
→ See: `AGENTS.md` → Example Workflows → Scenario 3

**"I need to setup security/permissions"**
→ See: `AGENTS.md` → Decision Tree → "Is it SECURITY/ACCESS related?"

**"I'm not sure which subagent to use"**
→ See: `AGENTS.md` → Decision Tree (flowchart)

### For Advanced Workflows

**Parallel Execution**
- Use when tasks don't depend on each other
- Invoke up to 4 subagents simultaneously
- Example: `AGENTS.md` → Pattern 2 (Multiple Independent Tasks)
- Saves: 50-70% execution time

**Sequential Chaining**
- Use when Task B depends on Task A completion
- Invoke sequentially with explicit ordering
- Example: `AGENTS.md` → Pattern 3 (Sequential Task Chain)
- Ensures: Proper dependencies and order

**Mixed Strategies**
- Use parallel for independent work, sequential for dependencies
- Example: `AGENTS.md` → Example Workflows → Scenario 1 (Full module)
- Best: Combines speed and correctness
