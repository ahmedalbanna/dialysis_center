================================================================================

1️⃣  APPOINTMENT WORKFLOW
    States: Draft → Scheduled → Check-In → In-Progress → Completed/Cancelled
    Transitions: 7
    Features:
    ✅ Auto-creates dialysis session on check-in
    ✅ Validates machine availability
    ✅ Prevents double-booking
    ✅ Tracks check-in and completion times
    ✅ Role-based access controls

2️⃣  DIALYSIS SESSION WORKFLOW
    States: Draft → In-Progress → Completed/Cancelled
    Transitions: 4
    Features:
    ✅ Comprehensive event logging
    ✅ Vital signs tracking
    ✅ Medication administration logging
    ✅ Equipment issue tracking
    ✅ Auto-invoice generation

3️⃣  INVOICE WORKFLOW
    States: Draft → Submitted → Partially Paid → Paid/Cancelled
    Transitions: 8 (with conditional approvals >5000)
    Features:
    ✅ Conditional manager approval
    ✅ Payment tracking & reconciliation
    ✅ Automatic refund processing
    ✅ Dunning management
    ✅ Complete financial audit trail

4️⃣  LAB TEST WORKFLOW
    States: Draft → Submitted → Results Received → Reviewed
    Transitions: 3
    Features:
    ✅ Lab order routing
    ✅ Result receipt tracking
    ✅ Doctor review and approval
    ✅ Trending analysis support

5️⃣  INSURANCE CLAIM WORKFLOW
    States: Draft → Submitted → Pending → Approved/Rejected/Cancelled
    Transitions: 7
    Features:

    ✅ Claim status tracking
    ✅ Approval workflows
    ✅ Denial management

QUICK START:

1. Create Audit DocTypes:
   bench --site frappe.local frappe-console
   >>> from dialysis_center.workflows.audit_doctypes import create_audit_doctypes
   >>> create_audit_doctypes()

2. Create Workflows:
   bench --site frappe.local frappe-console
   >>> from dialysis_center.workflows.workflow_definitions import create_all_workflows
   >>> create_all_workflows()

3. Clear Cache and Restart:
   bench --site frappe.local clear-cache
   bench restart

4. Verify Installation:
   bench --site frappe.local frappe-console
   >>> frappe.db.count("Workflow")
   # Should return 5

5. Test a Workflow:
   apt = frappe.get_doc({
       "doctype": "Appointment",
       "patient": "PATIENT-001",
       "appointment_date": "2026-02-25",
       "appointment_time": "09:00:00"
   })
   apt.insert()
   frappe.workflow.apply_workflow(apt, action="Schedule")
